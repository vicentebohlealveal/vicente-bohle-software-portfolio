# Medidor de grosor de cabello — FIS140

Herramienta web para registrar mediciones experimentales y apoyar el análisis/calibración del grosor de cabello. La interfaz permite trabajar con datos de medición y exportar resultados en formatos reutilizables.

## Ejecutar

Abrir `index.html` en un navegador moderno. No requiere instalación de paquetes ni servidor.

## Reproducibilidad

Antes de usar resultados como evidencia académica, revisar el procedimiento de medición, las unidades, la calibración y los supuestos de incertidumbre empleados por la herramienta.
