# Plataforma robótica de gran escala e IoT

Proyecto de integración electromecánica de una plataforma robótica con estructura mecánica, piezas impresas en 3D, ESP32, conectividad IoT, servomotores y manipuladores.

**Estado del código:** no se localizaron los archivos de firmware/control en las fuentes accesibles al preparar el portafolio. La carpeta documenta el proyecto; no representa código ejecutable.
