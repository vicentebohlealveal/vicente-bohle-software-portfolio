# Cargador para vehículos eléctricos y UPS/almacenamiento

Proyectos de electrónica de potencia y almacenamiento energético que incluyen integración de conversión y control y dimensionamiento/modelamiento de baterías.

**Estado del código:** el material disponible para este portafolio solo permite documentar el alcance general; no se localizaron fuentes firmware, simulaciones o CAD que se puedan atribuir y publicar con confianza.
